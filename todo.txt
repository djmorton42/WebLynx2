WebLynx2 TODOs
===============

Design decisions (intentional — do not port from WebLynx)
-----------------------------------------------------------
- Deprecated views omitted from SSO package: broadcast_race_overlay,
  broadcast_race_overlay_simple, broadcast_race_overlay_splits, lap_counter.
  Successor views (splits_bell, lap_counter_with_leader, etc.) cover production use.
- No web UI for config or key-value editing — Avalonia Configuration tab handles this.
- Half-lap mode is always on; no toggle in appsettings or UI.
- No server-side template injection ({{MEET_TITLE}}, {{VIEW_PROPERTIES}}, etc.).
  Views are dynamic: they poll /api/race/race-data for viewConfig and keyValues.
- HTTP server is GET-only; no /config, POST test endpoints, or Swagger.

Race-data API compatibility
---------------------------
[!] Always return halfLapModeEnabled: true in GET /api/race/race-data.

    Ported views read data.halfLapModeEnabled and fall back to false if missing:
        const halfLapModeEnabled = data.halfLapModeEnabled || false;
    Omitting this field breaks lap display for half-lap races.
